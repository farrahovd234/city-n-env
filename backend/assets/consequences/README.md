# Иллюстрации «Вестника города N»

Бекенд выбирает PNG по ID исхода. При `CITY_N_IMAGES=1` итог партии содержит
адрес картинки в `result.consequences.image_url` и отдельный текст газеты в
`result.consequences.herald_text`.

## Имена файлов

| Файл | Исход | Тема иллюстрации |
| --- | --- | --- |
| `open_river.png` | Открытая река | Работающие очистные, река и открытый общественный контроль; согласованные действия сторон. |
| `nedostroy.png` | Недострой | Незавершённые очистные, остановившийся проект и продолжающийся конфликт вокруг загрязнённой реки. |
| `without_residents.png` | Решили без жителей | Власти и предприятие приняли протокол без поддержки жителей и НКО. |
| `dolgostroy.png` | Долгострой | Уже введённые после долгого ожидания очистные и усталость жителей; без конкретного года или срока. |
| `holding_paid.png` | Холдинг заплатил за всех | Основная финансовая нагрузка на предприятии; без изображения банкротства или массовых увольнений. |
| `city_paid.png` | Город заплатил за всех | Реконструкция тяжело нагружает городской бюджет. |
| `closed_data.png` | Чистая вода, закрытые данные | Очистные работают, но жители не имеют доступа к независимым данным о реке. |
| `compromise.png` | Компромисс | Город добился улучшений, но сохраняются разногласия и нерешённые вопросы. |
| `each_for_self.png` | Каждый сам за себя | Разрозненные усилия участников без общего плана; не добавлять конкретных мер, которых может не быть в партии. |
| `stagnation.png` | Застой | Очистные не реконструированы, вокруг загрязнённой реки сохраняется затянувшийся конфликт. |
