# Город N

Город N — учебная игра о переговорах после экологической аварии. Река загрязнена, и пяти сторонам нужно договориться, кто оплатит реконструкцию очистных и на каких условиях.

Перед запуском партии игрок задаёт стратегии администрации, холдинга, региона, жителей и экологической организации. Доступны анкеты пяти ролей и автоматическое заполнение. Затем агенты проводят три раунда по пять реплик и голосуют за одну версию протокола. Для принятия нужны собранные 270 млн ₽ и пять голосов «за». Роль голосует «против», если протокол нарушает её красную линию. Итоговый экран показывает городскую газету, показатели за десять лет и разбор переговоров по выбранной роли.

## Запуск игры

Понадобятся Python 3.12 и `uv`. В PowerShell из корня репозитория выполните:

```powershell
.\start.cmd
```

Откройте [игру](http://127.0.0.1:8000/). FastAPI обслуживает интерфейс и API на одном порту.
`uv` установит зависимости по `backend/uv.lock`, а приложение загрузит `backend/.env`, если
файл есть. Для запуска партии подключите провайдера по инструкции ниже. Чтобы остановить
сервер, нажмите `Ctrl+C`. Если порт 8000 занят, запустите `.\start.cmd --port 8001`.

В Linux и macOS выполните из корня репозитория:

```bash
cd backend
uv run --locked python -m web_backend
```

### GigaChat через Gpt2Giga

Один раз скопируйте [шаблон](backend/gpt2giga.env.example) в `backend/gpt2giga.env` и укажите
в нём `GIGACHAT_CREDENTIALS` и нужный `GIGACHAT_SCOPE`. Затем запускайте игру так:

```powershell
.\start.cmd --gigachat
```

В Linux и macOS:

```bash
cd backend
uv run --locked --extra gigachat python -m web_backend --gigachat
```

Команда запускает локальный прокси и сервер игры. При остановке сервера она завершает
свой прокси. Адрес, модель и ключ прокси берутся из `backend/gpt2giga.env`, если для них
уже не заданы `CITY_N_LLM_BASE_URL`, `CITY_N_LLM_MODEL` и `CITY_N_LLM_API_KEY`.

### Прямое подключение OpenAI-совместимого провайдера

Провайдер должен поддерживать Chat Completions и function calling.
В `backend/.env` укажите базовый URL из документации провайдера, ID модели и
API-ключ, если требуется авторизация. Здесь можно подключиться и к уже
работающему OpenAI-совместимому прокси.

```dotenv
CITY_N_LLM_BASE_URL=https://provider.example/v1
CITY_N_LLM_MODEL=model-id
CITY_N_LLM_API_KEY=ключ_провайдера
CITY_N_IMAGES=1
```

Из корня репозитория запустите `.\start.cmd`.

### Запуск в Docker

С запущенным Docker Engine и Docker Compose выполните из корня репозитория:

```bash
docker compose up --build
```

Для прямого подключения к модели настройте `backend/.env` по примеру выше. Адрес модели должен быть доступен из контейнера.

Для GigaChat заполните `backend/gpt2giga.env` по [шаблону](backend/gpt2giga.env.example). В `backend/.env` задайте `CITY_N_LLM_API_KEY` со значением `GPT2GIGA_API_KEY` из этого файла. Compose сам задаёт внутренний адрес шлюза.

```bash
docker compose -f compose.yaml -f compose.gigachat.yaml --profile gigachat up --build
```

Игра доступна на [127.0.0.1:8000](http://127.0.0.1:8000/). Чтобы выбрать другой порт, задайте `CITY_N_HTTP_PORT` перед запуском Compose. Данные партий хранятся в томе `game-data` и переживают обычный перезапуск и `docker compose down`.

### Как запустить партию

Откройте [игру](http://127.0.0.1:8000/) и перейдите к настройке агентов.

- Для **ручной настройки** ответьте на вопросы каждой из пяти ролей и запустите партию.
- Для **автоматической настройки** нажмите «Настроить автоматически». Сервер проверит ответы и подготовит стратегии пяти сторон. Проверьте заполненные анкеты и запустите партию. Если изменить любой ответ, партия использует введённые настройки.

В автоматической настройке холдинг готов снизить мощность до 70%, как предлагает экологическая организация. В ручной анкете холдинга можно выбрать требование сохранить 100% мощности.

Суммы и сроки можно выставить ползунком или ввести рядом с ним. Взносы задаются целыми миллионами рублей в пределах бюджета стороны. Срок реконструкции задаётся целым числом от 24 до 48 месяцев. При подвозе воды на реконструкцию из городского бюджета остаётся не более 10 млн ₽.

При сроке свыше 36 месяцев жители требуют подвоза воды, а экологи — ограничения мощности завода до 70%. Если холдинг требует налоговых льгот за крупный взнос, правило применяется при взносе выше его комфортной суммы из анкеты.

Во время партии можно следить за журналом, поставить игру на паузу или остановить её. В итогах откройте «Помощника», выберите сторону и нажмите «Разобрать переговоры». Помощник даёт ссылки на журнал и показывает оценки вместе после разбора всех реплик стороны. Если повторный ответ модели снова не проходит проверку, Помощник добавляет наблюдение по самому журналу. Готовые оценки сохраняются в текущей вкладке. Если есть предложение по стратегии, оно появляется рядом с разбором.

Иллюстрации газеты включены по умолчанию. Для текстового режима задайте `CITY_N_IMAGES=0`.

Для работы напрямую с API отправьте `POST /api/v1/games` с пустым телом и случайным
`Idempotency-Key` (например, UUID). Сохраните выданную cookie владельца. В ответном
snapshot находятся `game_id` и анкеты со списками полей и значениями по умолчанию.
В числовом поле `number_range` задаёт допустимые границы и единицу измерения.
В `PUT /api/v1/games/{game_id}/settings` передайте `{"mode":"automatic"}` или
`{"mode":"manual","answers":{...}}` с ответами по идентификаторам пяти ролей. Затем
вызовите `POST .../start`.
Для изменяющих `POST` передавайте новый ключ и повторно используйте его только при
сетевом повторе того же запроса. Для HTTPS за обратным прокси можно явно включить
`CITY_N_SECURE_COOKIE=1`.

`GET .../{game_id}` возвращает полный snapshot. Для новых событий используйте
`GET .../{game_id}/events?after=<last_event_id>`. `message.created` добавляет реплику,
прочие события обновляют snapshot. При `EVENT_CURSOR_EXPIRED` возьмите новый snapshot.
Пауза действует между шагами. После завершения можно запросить анализ через
`POST .../analysis` с телом `{"role_id":"industrial_holding"}`. Если итоговый расчёт завершился ошибкой,
`POST .../retry-result` повторяет его с сохранёнными голосами.

Сессии доступны семь суток и привязаны к cookie браузера. Запускайте интерактивную
версию с одним worker. После перезапуска бэкенда завершённые игры и черновики доступны
по snapshot, незавершённые дебаты получают `GAME_INTERRUPTED`. Если голоса уже были
сохранены, расчёт можно повторить. Клиенты прежнего режима по-прежнему могут отправлять
`POST /api/v1/games` с телом `{"strategies": {...}}` или `{}` без заголовка идемпотентности.

[Swagger UI](http://127.0.0.1:8000/docs) · [Контракт API](backend/web_backend/openapi.json)

### Если возникла ошибка запуска

- При `Connection refused` проверьте, что процесс провайдера запущен и адрес в
  `CITY_N_LLM_BASE_URL` совпадает с его базовым URL. Для Gpt2Giga в примере
  используется `http://127.0.0.1:8090/v1`.
- При `401 Invalid API key` от локального прокси сверяйте `CITY_N_LLM_API_KEY`
  с `GPT2GIGA_API_KEY`.
  Если авторизацию отклоняет сам GigaChat, проверьте `GIGACHAT_CREDENTIALS` и `GIGACHAT_SCOPE`.
- При `failed` проверьте поле `error` в snapshot и журнал бэкенда. Прежний режим
  также записывает `backend/games/web/<game_id>/result.json`.

## Проверки

Автоматические тесты запускаются из папки `backend/`. Ответы модели в них подменены.

```bash
uv run --locked python -X utf8 -m unittest discover -s tests
```

## Зависимости Python

`backend/pyproject.toml` содержит прямые зависимости и опциональный набор `gigachat`.
`backend/uv.lock` фиксирует точные версии пакетов. Для установки используйте
`uv sync --locked`, для добавления нового пакета — `uv add <пакет>` из папки
`backend/`. После изменения зависимостей обновлённые `pyproject.toml` и
`uv.lock` идут в один коммит.
