# Город N

Город N — учебная игра о переговорах после экологической аварии. Река загрязнена, и пяти сторонам нужно договориться, кто оплатит реконструкцию очистных и на каких условиях.

Перед запуском партии можно задать стратегии администрации, холдинга, региона, жителей и экологической организации. Дальше ИИ играет за все пять сторон. Они предлагают взносы, обсуждают условия и голосуют за протокол. В конце игра показывает итоги переговоров и выпуск городской газеты о том, что произошло за следующие десять лет.

## Запуск бекенда

Нужны Python 3.12 и `uv`. Пример запуска рассчитан на работающий Gpt2Giga по адресу `http://127.0.0.1:8090/v1`.

```bash
cd backend
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements.txt
CITY_N_LLM_BASE_URL=http://127.0.0.1:8090/v1 CITY_N_IMAGES=1 \
  .venv/bin/python -m uvicorn web_backend.app:app --host 127.0.0.1 --port 8000
```

Модель по умолчанию — `GigaChat-3-Lightning`. Для другого совместимого провайдера укажите его адрес в `CITY_N_LLM_BASE_URL`, модель в `CITY_N_LLM_MODEL` и ключ сервера в `CITY_N_LLM_API_KEY`, если он требуется.

Откройте [Swagger UI](http://127.0.0.1:8000/docs). Чтобы сыграть со стандартными стратегиями, отправьте `POST /api/v1/games` с телом `{}`. За ходом и результатом партии следите по ссылке `status_url` из ответа. [Контракт API](backend/web_backend/openapi.json)

## Запуск демофронта

В папке `frontend/` находится демонстрационный интерфейс с заготовленными репликами и итогами. Интерфейс предстоит подключить к API.

Из корня репозитория запустите статический сервер и откройте [демо](http://127.0.0.1:5173/).

```bash
python3 -m http.server 5173 --bind 127.0.0.1 --directory frontend
```

## Проверки

Автоматические тесты запускаются из папки `backend/`.

```bash
.venv/bin/python -m unittest discover -s tests
```
