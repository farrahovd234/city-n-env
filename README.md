# Город N

Учебная веб-игра о переговорах после экологической аварии. Пять сторон решают, кто оплатит реконструкцию очистных и какие условия войдут в протокол. В финале городская газета показывает последствия решения через десять лет.

## Быстрый запуск

Понадобится запущенный Docker Engine или Docker Desktop с командой `docker compose`.

Для партии с GigaChat один раз скопируйте [.env.example](.env.example) в `.env` в корне репозитория. Вставьте Authorization Key из личного кабинета в `GIGACHAT_CREDENTIALS`. Для личного доступа в шаблоне уже указан `GIGACHAT_API_PERS`. При другом типе доступа укажите соответствующий `GIGACHAT_SCOPE`.

Запустите из корня репозитория.

```bash
docker compose up --build
```

Compose запустит игру и шлюз Gpt2Giga. Откройте [127.0.0.1:8000](http://127.0.0.1:8000/). Интерфейс и анкеты доступны до настройки ключа. Для другого порта измените `CITY_N_HTTP_PORT` в `.env`.

| Действие | Команда |
| --- | --- |
| Проверить состояние контейнеров | `docker compose ps` |
| Посмотреть логи | `docker compose logs -f game gpt2giga` |
| Остановить игру | `docker compose down` |

Черновики и завершённые партии хранятся в томе `game-data`. Обычная остановка и повторный запуск сохраняют том.

## Как проходит партия

1. Заполните анкеты администрации, холдинга, региона, жителей и Эко-НКО вручную или нажмите «Настроить автоматически». Готовые ответы можно отредактировать.
2. Агенты проводят три раунда по пять ходов. Для принятия протокола нужны собранные 270 млн ₽ и пять голосов «за». Нарушение красной линии даёт голос «против» от соответствующей стороны.
3. Когда заседание завершится, нажмите «Открыть газету» внизу журнала. В итогах будут иллюстрация и прогноз на десять лет. Помощник разбирает реплики выбранной стороны со ссылками на журнал и рекомендует, какие ответы в её анкете сохранить или изменить.
